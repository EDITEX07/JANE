
# JANE 🧠

**Judicious, Analytical, and Neuroresearch Engine**

JANE is a modular AI assistant designed to grow into a
business operating system for research, analysis,
decision support, and workflow automation.

## Current Version

JANE 0.1 — Initial AI Chat Application

## Initial Features

- AI-powered conversation
- Session-based conversation history
- Research and analytical assistance
- Business decision support
- Secure API key configuration through Streamlit Secrets

## Technology Stack

- Python
- Streamlit
- OpenAI API
- GitHub
- Streamlit Community Cloud

## Setup

1. Install the packages listed in `requirements.txt`.
2. Configure the `OPENAI_API_KEY` secret.
3. Run the application using Streamlit.

## Security

Never commit API keys, passwords, or other secrets
to the repository.
